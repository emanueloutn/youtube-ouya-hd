# Parche 0.1.1 — icono en MAKE → Software

Se corrige el manifiesto de la APK para que el acceso se incorpore a MAKE → Software al instalarla. El paquete y la firma se conservan: se puede actualizar sobre la versión anterior sin borrar sus datos.

No se cambian DEX, biblioteca nativa, reproducción H.264/AAC ni el ajuste HFR respecto a la APK 0.1.0. Los cortes y paros documentados siguen pendientes. La versión 0.1.1 identifica el parche; la base heredada mantiene su etiqueta Developer Build.
